System Performance Monitor

A bash-based system monitoring tool with a graphical user interface powered by Zenity. This tool provides real-time insights about a system. It supports Debian/Ubuntu distribution

Features

 * System Overview: Hostname, OS, Kernel, Architecture, Uptime, etc.,
 * CPU: Live Usage, Temperature, Core Count, Power Mode
 * RAM: Total Usage, Available Memory
 * Disk: Usage Details, Storage Info
 * Network: Bandwidth Monitoring
 * Processes: View top running processes
 * Batter Status
 * Wi-Fi Connected Devices
 * Hardware Details
 * Graphical Menu Bar

It will install all required packages.
The Script automatically install these packages if not already present
 * Zenity
 * ln-sensors
 * acpi
 * arp-scan
 * ifstat
 * gnuplot
 * libgtk-3-dev
 * vnstat
 * lshw
 * x11-utils
